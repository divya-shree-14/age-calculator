 
# 🎂 Age Calculator

A simple and responsive Age Calculator built using HTML, CSS, and JavaScript.

## 🌐 Live Demo
[Click here to use the Age Calculator](https://divya-shree-14.github.io/age-calculator/)

## ✨ Features
- Calculate age in years, months, and days
- Simple and user-friendly interface
- Date of birth input
- Validation for invalid and future dates
- Responsive design for different screen sizes

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Luxon Library

## 📂 Project Structure
age-calculator/
├── index.html
├── style.css
├── script.js
└── README.md

## 🚀 How to Run
1. Clone or download this repository.
2. Open index.html in your browser.
3. Select your date of birth.
4. Click Calculate Age.
